🧮 Calculator Web App

A simple and stylish calculator built using HTML and CSS. This project demonstrates clean UI design and basic frontend layout skills.

🚀 Features
-Basic arithmetic operations (+, −, ×, ÷)
-Clean and modern UI design
-Responsive layout
-Button hover effects
-Easy-to-use interface

🛠️ Technologies Used
-HTML5
-CSS3
